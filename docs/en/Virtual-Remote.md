The **Virtual Remote** lets you use the interface like a real physical remote, including button combinations and presses of different lengths.

### Why use the Virtual Remote?
This tool is essential if you have no physical remote to hand. It lets you:
* **Pair a new motor**, or one that has been reset (Factory Reset).
* **Set the motor's end limits** using button combinations.
* **Add other physical remotes** to your installation.
* **Simulate sensors** such as Sunis or Eolis devices.


### Using the interface

1.  **Selection**: use the drop-down menu at the top of the tab to choose the shade you want to control.
2.  **Long presses**: for a long press (e.g. the PROG button), click and hold the button (or press and hold on a touch screen).
3.  **Combinations**: you can click several buttons at once to send complex commands (e.g. Up + Down, or Down + My).
4.  **Extended commands (80-bit)**: specific commands such as *Step*, *Favorite* or *Stop* only appear if your motor is set to **80-bit** mode in its settings.

> [!IMPORTANT]
> Make sure you have selected the right shade before doing anything!


### Scenario: setting up without a physical remote
If you are starting from scratch with a blank motor:
1. Reset your motor (manufacturer's procedure).
2. Create a shade in the **Shades** tab of ESPSomfy-RTS.
3. Go to **Virtual Remote** and select that shade.
4. Use the virtual buttons to carry out the pairing procedure and set the limits, just as you would with a Telis or Situo remote.
